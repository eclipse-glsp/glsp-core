# Eclipse GLSP - GModel Demo Client

Client side of the `gmodel-demo` example language. `createGModelDemoDiagramContainer` creates a diagram container that registers the default model elements and views, plus the helper line, grid and debug feature modules.

The package is workspace-private and is used by the [playground](../playground) application. The server side is [`gmodel-demo-server`](../gmodel-demo-server).
